# Security reports

Do not report exploitable vulnerabilities, credentials or personal information in public issues.

Send private security reports to [admin@yanmeiai.com](mailto:admin@yanmeiai.com). Include the affected product version, platform, a concise description and sanitized reproduction steps. Never include passwords, access tokens or another person’s data.

This repository contains public documentation, not the proprietary application source. No response-time guarantee or bug bounty is established by this policy.
