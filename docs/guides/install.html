Find the official installer

  1. Visit the official website and check current platform availability.
  2. Follow the download or store link provided there. Confirm the application identity and publisher before installation.
  3. Follow the platform instructions and review any VPN permission request.
  4. Open the app and follow its onboarding. Select an available server and connect.
  5. Confirm the connection status in the app. Disconnect when finished.
