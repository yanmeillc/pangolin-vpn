# 安装与首次连接

> 各平台的下载地址、最低系统版本和具体安装步骤仍待核实。本指南暂不提供可执行的安装命令。

## 查找官方安装包

1. 访问[官方网站](https://pangolin.yanmeiai.com/)，确认当前支持的平台。
2. 使用官网提供的下载或应用商店链接。安装前核对应用名称和发布者。
3. 按照对应平台的说明安装，并仔细查看 VPN 权限请求。
4. 打开应用并按引导操作，选择可用服务器后连接。
5. 在应用中确认连接状态；使用完毕后断开连接。

## 待核实后补充的信息

- 支持的平台和最低操作系统版本。
- 官方下载或应用商店链接，以及对应版本。
- 各平台的权限、更新和卸载步骤。

如果安装或连接失败，请查看[故障排查](../support/troubleshooting.zh-CN.md)。
