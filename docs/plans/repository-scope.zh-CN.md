# 仓库基础结构

## 目标

为 Pangolin VPN 提供官方 GitHub 入口，发布产品介绍、功能说明、安装指南和公开技术文档。

## 初始目录

- 产品：产品范围、功能介绍和经核实的可用性信息。
- 指南：安装与首次连接。
- 技术：公开的连接模型与实现边界。
- 支持：常见问题、故障排查和安全反馈。
- 仓库工具：Issue 模板与本地链接检查。

## 后续文档工作

1. 核实平台支持、发布版本和官方下载地址。
2. 补充各平台安装说明及经过隐私处理的截图。
3. 根据已审阅的产品资料发布实现细节。
4. 添加经过核实的隐私政策、服务条款和版本信息链接。

以上是文档建设事项，不代表产品功能或发布日期公告。本次初始化不包含网站托管和部署。
