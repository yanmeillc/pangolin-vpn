# Product and features

Pangolin VPN aims to make VPN connections easy to manage through a consistent application experience.

## Product scope

- Encrypted VPN connections to help protect traffic in transit.
- Selection from available server locations.
- Simple connection and disconnection controls.
- Connection status and available usage information.

> This overview follows the repository’s existing product description. Platform support, individual features and service availability must be confirmed against current official information before installation or purchase.
