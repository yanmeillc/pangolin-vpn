# Troubleshooting and FAQ

[简体中文](troubleshooting.zh-CN.md)

## Cannot connect

1. Check whether your internet connection works with the VPN disconnected.
2. Check the app’s displayed error and current connection state.
3. If offered by the app, try another available server.
4. Check official product information for updates or service notices.

## Connection is slow

Compare the connection with the VPN disconnected and connected under similar conditions. Record the platform, app version, approximate time and selected region. Performance depends on network and service conditions; no fixed speed is promised.

## Where can I download the app?

Use the [installation guide](../guides/install.md) and official website. A verified download matrix has not yet been published here.

## How do I report a problem?

Use the repository’s bug report template for a sanitized, reproducible report. Include platform, app version, steps, expected result and actual result.

> GitHub issues are public. Remove account identifiers, IP addresses, tokens, subscription information and personal details from screenshots or logs before posting. For private support or security reports, contact [admin@yanmeiai.com](mailto:admin@yanmeiai.com).
