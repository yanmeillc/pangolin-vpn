# 常见问题与故障排查

## 无法连接

1. 断开 VPN 后，确认网络连接本身是否正常。
2. 查看应用显示的错误信息和当前连接状态。
3. 如果应用提供其他服务器选项，可以尝试切换服务器。
4. 查看官方产品信息，确认是否有更新或服务公告。

## 连接速度较慢

在相近的网络条件下，对比连接和断开 VPN 时的情况。记录平台、应用版本、大致时间和所选地区。速度受网络和服务状况影响，本项目不承诺固定速度。

## 从哪里下载应用？

请查看[安装指南](../guides/install.zh-CN.md)并通过官方网站确认。目前本仓库还没有经过核实的下载列表。

## 如何报告问题？

可以使用仓库中的 Bug 报告模板，提交经过清理且可复现的问题。请提供平台、应用版本、操作步骤、预期结果和实际结果。

> GitHub Issue 是公开的。发布截图或日志前，请删除账号标识、IP 地址、令牌、订阅信息和个人信息。私密支持或安全问题请发邮件至 [admin@yanmeiai.com](mailto:admin@yanmeiai.com)。
